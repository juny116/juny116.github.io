Minecraft LLM Agent

A text-based LLM agent connecting model decisions to actions in Minecraft Java.

Work: Ongoing

Design

The active v2 implementation uses language models to manage goals, plans, conversation, and memory. JEV selects actions and their arguments; a Mineflayer-based executor carries them out and records what actually changed.

Observations come from geometric sensing and remembered terrain. The agent does not read game screenshots or learn keyboard controls. Vision integration is a future direction.

Implementation

My recent implementation work connects automatic sensing to work actions, tracks placement progress and observed effects, and keeps planning and conversation running alongside execution.

The code includes movement, mining, item pickup, block placement, crafting, container interactions, eating, equipment, and melee combat. Goals and memory can persist across reconnections.

Open questions

Controlled checks cover individual actions and short task sequences. Reliable long-term survival and productive spontaneous cooperation have not been demonstrated.

Current issues include repeated actions with no valid targets, movement after building, execution gaps, goal transitions, and retrieval from distant memories. Implemented actions are not evidence of dependable autonomous play.
