Minecraft LLM Agent

Independent text-based agents combining hierarchical planning, personal memory, and chat-based cooperation in Minecraft.

Work: Ongoing

Problem

How can independent language-model agents turn goals and remembered experience into coordinated action in a shared Minecraft world?

Design & implementation

Each bot runs in its own process with personal memory. Bots cooperate through in-game chat, without shared memory or a central coordinator. Goal, task, and conversation LLM layers work with a fast action selector and a Mineflayer executor.

Agents query tools as needed, turn raw observations into decision-relevant facts, and apply lessons from reflection when relevant to the current situation. The system is text-based; vision is not implemented.

Observed progress

Cooperating bots have built shelters and a base camp, and made iron-tier equipment. These outcomes demonstrate completed tasks, not a measured success rate.

Open questions

Repeatability has not been measured. Further evaluation is needed to understand how consistently memory, planning, and chat-based coordination support longer tasks.
