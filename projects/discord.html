Discord LLM Bot

A conversational Discord bot combining speaker-aware messages, bounded recent context, and optional retrieval memory across model backends.

Problem

Group conversations involve multiple speakers and more history than a model can use at once. The bot connects Discord messages to a shared conversation interface while retaining who said what and selecting context for each reply.

Design & implementation

Messages retain author names, and Discord mentions are converted into readable names for model input. The bot records conversation context and replies when mentioned. Recent messages are selected within a token budget, with the system prompt retained.

Optional Elasticsearch memory stores conversation chunks and retrieves a matching chunk using the latest message. Retrieved messages are combined with recent context before generation. Shared event and memory handling supports both earlier model loaders and direct OpenAI or Gemini API adapters.

Current functionality

Commands reset or save conversation history, update the prompt, adjust token and turn limits, and store or query retrieval memory. Generation runs in a worker thread while incoming messages are processed sequentially.

Limitations

Retrieval uses text matching rather than a learned memory policy. Retrieved context is added outside the recent-history token budget, and v2 token counts use a common tokenizer estimate rather than provider-specific accounting. Sequential processing also means a slow response delays later messages.
