Memory for web agents

Studying experience reuse in web agents through evaluation and analysis of memory and agent behavior.

Paper: Under review

Research question

This research studies episodic memory for web agents: using records of past interactions to support subsequent tasks. The central question is how an agent can find useful information in prior experience and relate it to its current goal.

Approach

I study what experience to retrieve, when to provide it, and how it can support the next decision. The work combines controlled evaluation with analysis of agent behavior to examine the relationship between memory access and effective reuse.

Open questions

Current work focuses on how agents can connect relevant procedures from past experience to the demands of a new situation. The broader goal is to understand when memory supports decision-making and how to make that support more useful.

The manuscript is under review. Follow-up analysis and experiments are in preparation.
