Memory for web agents

Separating the effects of initial guidance and continued memory access in web agents.

Paper: Under review

Research question

When web agents reuse a fixed bank of past experiences, how much comes from guidance at the start of a task, and what does continued memory access add?

Approach

The study separates initial guidance from continued access to the same experience bank, evaluating how each relates to the agent’s decisions and task execution.

Observations & open questions

Initial guidance from successful experiences has shown benefits. An additional benefit from continued retrieval has not yet been established. Ongoing analysis examines when further memory access helps beyond that initial guidance.
